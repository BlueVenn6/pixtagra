# PixTagra 隐私政策

更新：2026-11-18。维护者：Nera Venn；邮箱：neravenn@gmail.com。

PixTagra 是一个在你的电脑上运行的本地桌面程序。它不内置账号系统，不自动上传你的图片、密钥或日志，也没有内置的行为统计或广告。

## 在本机处理的内容

PixTagra 在你的设备上读取图片、编辑元数据、保存配置和工作区恢复记录。默认配置目录为当前 Windows 用户目录下的 `.picture_seo_studio`，可通过环境变量修改位置。

工作区恢复数据库可能包含：图片路径、文件大小与修改时间、标题、描述、关键词、选择状态和生成阶段。它用于程序意外退出后恢复进度，**不包含图片本身的字节，也不包含 API 密钥**。

本地配置、工作区和导出文件保留至你自行清除或删除。卸载程序只移除安装文件，不会删除这些用户数据。

## 发送到外部的数据

只有在你主动点击分析、重新生成或视觉复核时，并且**只有在你配置了云端服务商的情况下**，以下内容才会发送到你自己配置的那个地址：

- 图片的压缩副本（长边最长 768 像素）
- 提示词与待复核的元数据
- 用于鉴权的 API 密钥

连接测试也会向所选端点发送一次鉴权请求。接收方可能是 OpenAI、Qwen、Kimi、MiniMax 等官方服务商，也可能是你自行填写的中继地址——**实际接收方完全取决于你的配置**。它们的保存期限、处理地点和再使用规则以各自政策为准，跨境服务可能在中国大陆以外处理数据。

使用本地 Ollama 并保持默认环回地址时，请求不会离开本机。若你把它改成远程地址，就不再属于本地处理。

请勿上传你无权提供的敏感图片。

## API 密钥

密钥保存在 Windows 凭据管理器中，解锁流程使用 Windows Hello。只有在明确选择"保存到 Windows"时才会持久化，否则只在本次会话内有效。

密钥不会被写入图片、CSV 或 JSON 导出文件。诊断输出会脱敏（例如显示为 `sk-***abc`），但可能保留模型名称、端点主机、状态码、错误分类和本地文件路径。把诊断信息发给他人前请自行检查。

## 维护者会收到的信息

只有当你主动发邮件时，维护者才会收到你的邮箱地址、邮件内容和主动附上的文件，这些仅用于回复和排查问题。请不要在邮件中发送密钥、密码或无关的私人照片。

本软件免费提供，没有订单、支付或退款流程，因此维护者不持有你的交易记录。

## 你的选择

你可以随时清除应用配置目录中的本地记录，通过应用内的凭据管理流程或 Windows 凭据管理器删除保存的密钥。若要删除已经发送给第三方服务商的数据，需要向该服务商直接申请——仅卸载本软件不会撤回已发送的内容。

你可以通过上述邮箱要求访问、更正或删除维护者因邮件往来而持有的你的信息。

本软件不面向未成年人。政策如有重要变更会更新本文件的版本日期。
